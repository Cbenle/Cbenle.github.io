# Research Projects

## Stock Market Liquidity
Predicting stock market liquidity using regression modeling, firm characteristics, and model diagnostics.

[View code and results](https://github.com/Cbenle/stock-liquidity-regression)

## Treasury PCA Volatility
Constructing monthly and annual volatility measures from Treasury yield principal components and comparing them with VIX.

[View code and results](https://github.com/Cbenle/Treasury-PCA-volatility)

## Treasury Bond PCA: AR and VAR Analysis
Time-series analysis of Treasury PCA-based series (PC1 and PC2) using autoregressive and vector autoregressive models in R.

[View code and results](https://github.com/Cbenle/Treasury-Bond-PCA-AR-VAR)
